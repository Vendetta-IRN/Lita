CUSTOM FONTS
============
Put your font files in:   app/src/main/res/font/

  lita_font_en.ttf        -> font for English   (.otf also works; keep the name lita_font_en)
  lita_font_fa.ttf        -> font for Persian   (.otf also works; keep the name lita_font_fa)

Optional bold versions (otherwise bold is synthesized from the regular file):
  lita_font_en_bold.ttf
  lita_font_fa_bold.ttf

Rules: lowercase letters, digits and underscores only; exactly these names. Use fonts you have the licence for.
If a file is missing, the system font is used for that language (the app still builds).
